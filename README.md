# Sanadak (سندك)

An Arabic RTL landing site for professional furniture moving in Alexandria — packing, disassembly/assembly, and safe transport — with quote request flow, FAQ, testimonials, and an admin area.

Brand line from the app: **سندك | نقل عفش في الإسكندرية**.

## Who it's for

- Local moving businesses that want a conversion-focused Arabic site
- Agencies shipping a ready marketing + quote funnel for movers
- Teams needing RTL / Arabic typography done right (Almarai + Montserrat)

## What you get

- Premium hero, services, how-it-works, testimonials, FAQ
- Quote form + thank-you page
- Admin section under `/admin`
- Supabase client wired for data
- Vercel Analytics
- Live demo: [v0-furniture-moving-website-eight.vercel.app](https://v0-furniture-moving-website-eight.vercel.app)

## Try it

**Live:** [Open Sanadak](https://v0-furniture-moving-website-eight.vercel.app)

**Local:** sync Node deps, then run the `dev` script from `package.json` (http://localhost:3000). Configure any Supabase env vars before expecting live form/admin data.

## Stack

Next.js · React · TypeScript · Tailwind · Framer Motion · Supabase · shadcn/ui · RTL Arabic UI
